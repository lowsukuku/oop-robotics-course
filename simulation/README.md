# Сцена MuJoCo задачи сортировки шаров

Сцена построена на моделях UR5e и Robotiq 2F-85 из
[MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie). Источники моделей,
лицензии и сведения о локальных изменениях — в
[models/mujoco_menagerie/README.md](models/mujoco_menagerie/README.md).

## Геометрия

Мировая система координат совпадает с системой основания манипулятора. Начало — центр
нижней поверхности основания на столе (z = 0), +x направлена к контейнерам, +y — вперёд.

| Элемент | Размеры |
| --- | --- |
| Рабочая зона (плоская часть стола) | 0.6 × 0.6 м: x, y ∈ [−0.30, 0.30]; в центре — манипулятор |
| Воротник вокруг основания | усечённый конус: радиус у стола 0.22 м, высота 0.02 м |
| Скосы слева, спереди и сзади | от границы рабочей зоны до ограждения: ширина 0.30 м, высота у стенки 0.034 м |
| Скос перед контейнерами | ширина 0.08 м, высота у стенки 0.02 м |
| Контейнеры | x ∈ [0.38, 0.532]; синий — y ∈ [0, 0.60], красный — y ∈ [−0.60, 0]; внутри 150 × 598 × 300 мм, стенки 1 мм |
| Ограждение | стенки высотой 0.9 м: x ∈ [−0.60, 0.532], y ∈ [−0.60, 0.60] |
| Шары | `ball_0` … `ball_9` синие, `ball_10` … `ball_19` красные; диаметр 68 мм, масса 280 г |
| Точка подачи шаров | (−0.25, 0, 0.9) |

На скосе или воротнике шар остановиться не может — он скатывается на плоскую часть стола.
Поэтому покоящиеся шары лежат не ближе 0.22 м к оси основания и не ближе 0.30 м
к ограждению. В этой области захват сверху достижим, а раскрытому захвату и локтю
манипулятора хватает места.

Начальное состояние задаёт keyframe `initial`:
- манипулятор сложен: TCP в точке (0.25, 0, 0.45), захват направлен вниз и раскрыт;
- шары лежат в контейнерах своего цвета.

## Файлы

| Файл | Назначение |
| --- | --- |
| `ball_sorting/generate_scene.py` | генератор сцены; все размеры заданы в `SceneParams` |
| `ball_sorting/scene.xml` | сцена, созданная генератором; её загружает симулятор |
| `ball_sorting/scene.png` | изображение сцены |

После изменения размеров сцену нужно создать заново:

```bash
python3 simulation/ball_sorting/generate_scene.py
```

## Просмотр без ROS

```bash
/opt/ros/jazzy/opt/mujoco_vendor/bin/simulate simulation/ball_sorting/scene.xml
```

В окне выберите keyframe `initial` (панель *Simulation → Key*, кнопка *Load key*) и
снимите паузу.

## Модель захвата

В `models/mujoco_menagerie/robotiq_2f85/2f85.xml` добавлены:

- точка `tcp` на оси захвата, на высоте центров подушечек при раскрытии 68 мм. Позы
  захвата задаются для этой точки;
- позиционный привод, который действует на оба пальца через сухожилие `split`.
  Управляющий сигнал — угол ведущего звена: 0 — захват раскрыт, 0.8 — сжат. Усилие
  сжатия ограничено параметром `forcerange`: значение 3.14 даёт около 32 Н на подушечку.
